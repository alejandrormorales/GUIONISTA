# Guionista

Editor de guiones de cine que se instala como app en Windows y iPad y funciona sin conexión.

- Windows: abre la web en Edge o Chrome y pulsa el icono «Instalar» de la barra de direcciones.
- iPad: ábrela en Safari → Compartir → «Añadir a pantalla de inicio».
